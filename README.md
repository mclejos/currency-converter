# Currency Converter Project

This is a simple currency converter I built. 

## What I used to build it:

* **HTML**: Used to create the structure of the webpage, like the form, inputs, and dropdowns.
* **CSS**: Used to style the webpage and make it look nice.
* **JavaScript (Frontend)**: Used to listen to user input on the webpage and send requests to the server without reloading the page.
* **Node.js & Express (Backend)**: Used to create a server that handles the conversion requests and gets the exchange rates.

## How to run it:

1. Open your terminal in this folder.
2. Run `npm install` to install dependencies.
3. Run `node server.js` or `npm start` to start the server.
4. Open your browser and go to `http://localhost:3000` (or whatever port it shows).
